Miletos documentation
======================

I use Miletos to search time-series observations and test astrophysical models
against photometric and radial-velocity measurements. Transit searches, vetting,
completeness measurements, and forward modeling live in the same analysis
package, so a candidate signal can be followed through to the model that might
explain it.
